# FilmX Mobile (React Native Android App)

O'zbek tilidagi barcha yangi tarjima kinolar, premyeralar va to'liq faslli seriallar portali.

## ✨ Xususiyatlar
- ⚡ **60fps Yengil va Tezkor**: FlatList optimallashtirilgan silliq interfeys
- 🎬 **918+ Asar**: Barcha kinolar va seriallar Tas-ix yuqori tezlikdagi oqimda
- 📺 **Kuchli Video Player**: 10s o'tkazish, tezlik (0.75x - 2x), sifat (1080p FHD), uyqu taymeri
- 🔁 **Seriallar Avto-ijrosi**: Keyingi qismga 5s hisoblagich bilan avtomatik o'tish
- ❤️ **Sevimlilar va Ko'rish Tarixi**: AsyncStorage orqali avtonom saqlash
- 🔍 **Katalog va Qidiruv**: Janr, davlat, yil va reyting bo'yicha qulay filtrlash

## 🚀 Avtomatlashtirilgan APK Qurish (CI/CD)
Ushbu repozitoriyda `.github/workflows/build-apk.yml` GitHub Actions o'rnatilgan. Har bir yangi kod yuborilganda yoki qo'lda ishga tushirilganda, GitHub avtomatik ravishda Android APK faylini quradi va Releases bo'limiga yuklaydi.
